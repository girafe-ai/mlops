# Cityscapes dataset

[Cityscapes](https://www.cityscapes-dataset.com/dataset-overview/) is a dataset of
urban street scenes from 50 cities for semantic and instance segmentation. It
includes 5,000 finely annotated images and 20,000 coarsely annotated images.
The official site provides [annotation examples](https://www.cityscapes-dataset.com/examples/).

Access requires [registration](https://www.cityscapes-dataset.com/register/) and
acceptance of the [dataset terms](https://www.cityscapes-dataset.com/license/).
The [download guide](download.md) explains how to save the standard image and fine
annotation archives locally.
